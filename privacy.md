# Privacy Policy

JetBackup Drive Connector is a private tool used only by its owner.

## What data is accessed

The app accesses only the owner's own Google Drive, and only to upload, list, download and delete backup files created by JetBackup on the owner's server.

## How data is used

Data is used only to store and restore the owner's server backups. No data is collected from any other person.

## Sharing

No data is sold, shared with, or transferred to any third party.

## Storage and security

Backup files are stored in the owner's Google Drive. OAuth tokens are stored only on the owner's server.

## Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions
